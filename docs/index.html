How it is different

A note is not a menu.

  • [ ]They read the note. Write “pizza” and somebody goes to fetch one.
  • [ ]They live on the taskbar, between your windows, not inside an app.
  • [ ]Real windows on coloured paper, still there after a reboot.
  • [ ]12 MB, near-zero CPU. No account, no telemetry, nothing phones home.
  • [ ]Ctrl+Alt+N drops a note where your pointer is.
  • [ ]Right-click a note, open Scenes, and ask for the pizza now.
  • [ ]An angry note makes a grumpy man. He says “hmph”.
